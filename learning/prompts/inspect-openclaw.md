# 任务：分析 OpenClaw 源码并生成完整架构图系列

## 🎯 任务目标

请深入分析当前目录下的 OpenClaw 源码，生成一套完整的架构图系列，帮助我完全理解项目的运作原理。

## 📁 分析范围

请重点分析以下目录：

- `src/` - 核心源码
- `config/` - 配置文件
- `package.json` / `pyproject.toml` - 项目依赖和入口
- `docs/` - 官方文档（如有）
- `README.md` - 项目说明

## 📐 需要生成的架构图（共 6 张）

### 图 1：系统上下文图 (System Context Diagram)

**目的**：展示 OpenClaw 与外部系统的关系
**要求**：

- 标识所有支持的消息渠道（WhatsApp、Telegram、Discord、Slack、飞书等）
- 展示与外部 LLM 服务的连接
- 展示与本地文件系统的交互
- 使用 C4 模型的系统上下文格式

**输出格式**：Mermaid

---

### 图 2：四层架构总览图 (Four-Layer Architecture)

**目的**：展示四层架构模型的整体结构
**要求**：

- 清晰展示四层：交互层、网关层、智能体层、执行层
- 标注每层的核心模块/目录
- 展示层间数据流向和调用关系
- 标注关键接口和协议

**输出格式**：Mermaid

---

### 图 3：消息流程序列图 (Message Flow Sequence)

**目的**：追踪用户消息从进入到响应的完整链路
**要求**：

- 从用户发送消息开始
- 经过交互层 → 网关层 → 智能体层 → 执行层 → 返回
- 标注每个步骤对应的源文件和方法名
- 展示同步/异步调用关系

**输出格式**：Mermaid Sequence Diagram

---

### 图 4：模块依赖图 (Module Dependency Graph)

**目的**：展示代码模块间的导入/依赖关系
**要求**：

- 分析 `src/` 目录下各模块的 import 关系
- 识别核心模块和边缘模块
- 标注循环依赖（如有）
- 使用不同颜色区分模块类型

**输出格式**：Mermaid 或 DOT

---

### 图 5：记忆系统数据流图 (Memory System Data Flow)

**目的**：展示三级记忆系统的读写流程
**要求**：

- 展示短期记忆、长期记忆、语义记忆的存储位置
- 标注记忆的写入时机和读取时机
- 展示记忆与 Agent 的交互关系
- 标注关键数据结构和格式

**输出格式**：Mermaid Data Flow Diagram

---

### 图 6：部署拓扑图 (Deployment Topology)

**目的**：展示本地/远端节点的部署结构
**要求**：

- 展示本地运行时的组件分布
- 展示远端节点（如有）的连接方式
- 标注网络端口和通信协议
- 展示配置文件的加载路径

**输出格式**：Mermaid
